# Темы оформления от дизайнера

Сюда кладутся темы оформления — по одному JSON-файлу на тему. При сборке (`npm run build`, `npm run dev`, тесты)
каждый файл автоматически попадает в реестр тем игры (`src/theme/registry.ts`) и проверяется `parseTheme`.
Некорректный файл ломает сборку с сообщением, в каком файле и в каком поле ошибка.

## Правила

- Файл называется по id темы: `<id>.json` (например, `high-contrast.json` для `"id": "high-contrast"`).
  id — латиница в нижнем регистре, цифры, дефис; не повторяется и не равен `dark-fantasy` (это встроенная тема по умолчанию).
- Формат — тот же, что у встроенной темы «Тёмное фэнтези» (`src/theme/darkFantasy.ts`); тип и полный список ключей —
  `src/theme/types.ts`. Нужны **все** ключи всех групп, лишние ключи — ошибка:
  - `id`, `name` (название для игрока), `colorScheme` (`"dark"` или `"light"`);
  - `colors`, `map`, `dice` — цвета: `#rgb`, `#rrggbb`, `#rrggbbaa`, `rgb()/rgba()`, `hsl()/hsla()`;
  - `fonts` — семейства шрифтов CSS;
  - `fontSizes`, `space`, `radii` — длины: `12px`, `0.85rem`, `50%`;
  - `shadows` — тени CSS; могут ссылаться на цвета темы: `"0 0 8px var(--dice-nat20-glow)"`.
- Контраст текста проверяется тестом по WCAG AA — не меньше 4.5:1 (у темы с id `high-contrast` — 7:1). Пары «текст на фоне» —
  `CONTRAST_PAIRS` в `src/theme/contrast.ts`; полупрозрачные цвета считаются по итоговому цвету на их фоне.

## Как посмотреть тему

Добавьте к адресу сайта `?theme=<id>`, например `https://mr-rubenss.github.io/dnd_ai_master/?theme=high-contrast`.
Тема включается только для этой вкладки и нигде не сохраняется. Скриншоты главного экрана и создания персонажа для
каждой темы на телефоне сохраняет e2e-тест `e2e/themes.spec.ts` (в отчёте Playwright).
